# 레오파드 모프 계산기 — 업로드 안내

## GitHub 업로드 (매번 동일)
1. https://github.com/Art-lyang/REPTILE
2. **Add file → Upload files**
3. 아래 4개 파일을 **한꺼번에** 끌어다 놓기 (폴더째 X, 파일만)
   - index.html      계산기 + 관리자(#admin)
   - gecko-core.js   ★ 필수! 없으면 모프가 안 보임
   - breeding.html   브리딩 관리 (프리미엄)
   - login.html      로그인 / 회원가입   ← 이번 추가
4. **Commit changes** → 1~2분 후 반영

## 주소
- 계산기   https://art-lyang.github.io/REPTILE/
- 로그인   https://art-lyang.github.io/REPTILE/login.html
