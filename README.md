# 레오파드 모프 계산기

## GitHub 업로드 방법
1. https://github.com/Art-lyang/REPTILE 접속
2. **Add file → Upload files**
3. 이 폴더의 **파일 4개를 한꺼번에** 끌어다 놓기
   - index.html      (계산기 + 관리자)
   - gecko-core.js   ← **필수! 없으면 모프가 안 보입니다**
   - breeding.html   (브리딩 관리)
   - supabase_setup.sql (DB 설정용, 웹에는 영향 없음)
4. 아래 초록색 **Commit changes** 클릭
5. 1~2분 뒤 https://art-lyang.github.io/REPTILE/ 접속

※ 반드시 세 파일(index.html, gecko-core.js, breeding.html)이
   **같은 위치(루트)** 에 있어야 합니다. 폴더 안에 넣지 마세요.
