# 크레스티드 모프 계산기 — 안내

레오파드 계산기(`index.html` / `gecko-core.js`)와 **완전히 별개**입니다.
서로 파일도, 변수 이름도 겹치지 않으니 한쪽을 고쳐도 다른 쪽에 영향이 없습니다.

## 파일 (2개)

| 파일 | 설명 |
|---|---|
| `crested.html` | 계산기 화면 · 4개 국어 사전 · 업데이트 노트 |
| `crested-core.js` | ★ 필수. 모프 데이터 + 계산 엔진 |

두 파일은 **같은 폴더**에 있어야 합니다. `crested-core.js` 가 없으면 안내 화면만 뜹니다.

## 나중에 GitHub 에 올릴 때

1. 저장소를 만들고 위 2개 파일을 업로드
2. 주소는 `.../crested.html`
3. `crested.html` 아래쪽의 **이용약관 · 개인정보처리방침** 링크가 `terms.html` 을 가리킵니다.
   - 레오파드와 같은 저장소에 올리면 그대로 동작합니다.
   - **새 저장소로 분리한다면** `terms.html` 도 같이 올리거나, 해당 링크 줄을 지워주세요.

### 파일을 고쳐서 다시 올릴 때 — 꼭 확인

`crested.html` 위쪽에 이런 줄이 있습니다.

```html
<script src="crested-core.js?v=20260727a"></script>
```

`crested-core.js` 를 수정해서 올릴 때는 **`?v=` 뒤 숫자를 바꿔주세요.**
안 바꾸면 이미 방문했던 사람의 브라우저가 예전 파일을 계속 사용합니다.

## 계산 모델

첨부해 주신 `크레모프계산기_참조.xlsx` 를 기준으로 만들었고, 리서치 결과 **한 가지를 바로잡았습니다.**

### 카푸치노와 세이블은 같은 자리(대립유전자)입니다

엑셀은 둘을 독립된 두 자리로 두고 계산합니다. 그러면 실제로는 존재할 수 없는 조합이 생깁니다.

| 엑셀의 C×S | 실제 의미 | 가능? |
|---|---|---|
| `cc ss` | 노멀 | ✅ |
| `Cc ss` | 카푸치노 | ✅ |
| `cc Ss` | 세이블 | ✅ |
| `CC ss` | 슈퍼카푸치노 | ✅ |
| `cc SS` | 슈퍼세이블 | ✅ |
| `Cc Ss` | **루왁 (Luwak)** ← 엑셀은 「카푸세이블」로 계산 | ✅ (이름만 정정) |
| `CC Ss` | — | ❌ 불가능 |
| `Cc SS` | — | ❌ 불가능 |
| `CC SS` | — | ❌ 불가능 |

한 마리는 이 자리에 유전자를 **2개**만 가질 수 있어서, 슈퍼카푸치노(C·C)이면서 세이블(S)일 수는 없습니다.
보내주신 스크린샷에 **루왁** 칩이 있는 것도 이 모델이 맞다는 근거입니다.

그래서 기본 모드는 카푸치노·세이블을 **3대립유전자 한 자리**로 계산합니다.

- 슈퍼세이블 × 슈퍼카푸치노 → **100% 루왁**
- 루왁 × 노멀 → 카푸치노 50% / 세이블 50% (루왁은 안 나옴)
- 루왁 × 루왁 → 루왁 50% / 슈퍼카푸치노 25% / 슈퍼세이블 25% (**노멀이 안 나옴**)

### 엑셀과의 대조 (개발 중 검증 완료)

만드는 과정에서 엑셀의 6자리 모델을 그대로 재현해 **729행 전부 · 확률 소수점까지 일치**하는 것을
확인했습니다. 그 뒤 위의 정정 사항을 반영했으므로, 엑셀 호환 모드는 화면에 넣지 않았습니다.

지금도 자동 테스트에서 **카푸치노·세이블이 둘 다 야생형인 구간(엑셀 81행)** 을 매번 대조하고 있어,
릴리·팬텀·초초·아잔틱 4자리는 엑셀과 계속 일치합니다.

### 그 밖에 바로잡은 것

- **프라푸치노 = 카푸치노 + 릴리화이트** (카푸치노 + 세이블이 아닙니다 — 그건 루왁)
- **슈퍼릴리화이트는 치사 유전** — 성체가 존재하지 않으므로 **부모로 고를 수 없습니다.**
  릴리화이트끼리 교배했을 때 새끼 결과에만 `비생존` 으로 표시되고,
  **[생존 개체 기준으로 보기]** 를 누르면 비생존을 빼고 다시 나눈 확률(릴리 2 : 노멀 1)을 보여줍니다.
- **슈퍼카푸치노 건강 주의** — 약 100마리 표본에서 콧구멍 이상 약 11%(일부는 탈피 잔여물), 스펙타클 아이 3% 미만 보고.
  슈퍼카푸치노는 생존하므로 부모로 고를 수 있고, 대신 ⚠ 경고가 붙습니다.
- **팬텀 · 초초** 는 유전 방식이 브리더 사이에서 완전히 합의되지 않아 `미확정` 배지를 답니다.
