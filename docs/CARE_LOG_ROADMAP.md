# 크리처 케어로그 — 사육·브리딩 이력 확장 계획

기준일: 2026-08-03

## 이번에 완료한 범위

### 구조화 급여 기록

- 먹이 출처: 등록한 먹이 목록 또는 직접 입력
- 먹이 종류: 슈퍼푸드·사료, 곤충, 통먹이, 식물성, 영양제, 기타
- 급여 상태: 바로 급여, 생먹이, 냉동, 해동, 분말, 혼합, 신선, 기타
- 급여 결과: 전부 먹음, 일부 먹음, 거부, 확인 안 함
- 수량: 제공량, 실제 섭취량, 단위
- 부가 정보: 날짜, 메모
- 달력과 최근 기록에 먹이명·상태·양·결과를 함께 표시
- 기존 먹이 재고와 연결된 기록은 제공량을 기준으로 재고를 차감하고, 기록 삭제 시 복구
- 한국어, 영어, 중국어, 일본어 문구 계약 유지

### 데이터와 보안

- `supabase_v42.sql`: 구조화 급여 컬럼, 값 검증, 소유권 검사, 재고 연동 트리거
- `supabase_v43.sql`: 급여·케어 기록 정책의 인증 검사 성능 보완
- `supabase_v44.sql`: 수컷 1마리와 암컷 최대 12마리를 묶는 메이팅 그룹, 암컷별 정확한 페어링, 날짜별 메이팅 기록
- `supabase_v45.sql`~`supabase_v47.sql`: 익명 권한 회수, 소유자·혈통 조회 인덱스, 기록이 있는 그룹 구성원 보호
- 기존 한 번 누르기 방식 급여 기록도 그대로 읽을 수 있도록 하위 호환 유지
- 라이브 Supabase에 v42~v47 적용 완료

### 메이팅 그룹과 혈통 점검

- 성체 수컷 1마리와 같은 종의 성체 암컷 1~12마리를 한 시즌 그룹으로 관리
- 1:2·1:3 그룹도 암컷마다 기존 1:1 페어링을 자동 생성해 클러치와 자손의 부·모를 정확히 연결
- 각 암컷과 대표 수컷 사이의 최대 3세대 공통 조상·직계 조상·혈통 누락을 그룹 카드에서 구분
- 합사·구애·교미 확인·미확인·분리 결과를 날짜와 메모로 기록
- 기존 개별 1:1 페어링은 별도 목록으로 유지
- 라인브리딩 프로젝트를 그룹에 연결하면 생성된 암컷별 페어링이 기존 프로젝트 분석에 포함

### 산란·부화 결과와 자손 연결

- 클러치별 유정·무정·발달 중지·부화·미확인 알 수 기록
- 실제 부화일과 클러치 마감 상태 저장
- 부화 수보다 많은 자손을 등록하지 못하도록 서버에서 제한
- 부화 개체 등록 시 정확한 부·모, 클러치, 해칭일, 라인브리딩 프로젝트 다음 단계 자동 연결
- 메이팅 기록부터 산란·부화 예정·실제 부화·자손 등록까지 타임라인 표시
- 한국어·영어·중국어·일본어 문구와 오류 안내 동시 제공

## 랩다이어리 참고 기능 적용 원칙

다른 앱의 화면을 그대로 복제하지 않고 다음 원칙으로 크리처 케어로그에 녹인다.

1. 빠른 기록은 입력 부담을 낮춘다.
2. 실제 사육 판단에 필요한 정보는 덮어쓰지 않고 날짜별 이력으로 남긴다.
3. 달력에서 날짜를 누르면 그날 한 일과 먹이·양·메모를 한눈에 보여준다.
4. 종별 차이는 공통 데이터 구조와 종별 프리셋을 조합해 처리한다.
5. 건강 판단을 단정하지 않고 기록 누락과 일정 도래를 알려주는 보조 기능으로 제한한다.

## 다음 구현 순서

### 1. 결제와 이용 권한 기반

- PG사와 분리된 상품·주문·결제·환불·구독·이용 권한 데이터 구조
- 기존 프리미엄 코드도 동일한 이용 권한 발급 경로로 통합
- 중복 결제 알림과 재시도에도 한 번만 처리되는 서버 검증 경계
- 이니시스 또는 카카오 결제 모듈은 서버 어댑터로 연결하고 브라우저에 비밀키를 두지 않음
- 유료 공개 전 이용약관·개인정보처리방침·환불 정책·사업자 고지 복원

### 2. 월간 기록 모아보기

- 먹이, 체중, 배변, 탈피, 건강, 메모, 번식 기록 필터
- 날짜 칸에 종류별 작은 표시와 건수 제공
- 날짜 선택 시 그날의 상세 기록을 같은 화면에서 표시
- 개체별·전체 개체 범위 전환

### 3. 스마트 리마인더

- 마지막 급여·체중·청소·탈피 기록 후 경과일 표시
- 반복 계획이 밀렸을 때만 주의 상태 표시
- 먹이 재고 부족 예상과 다음 급여 계획 연결
- 종별 기준을 진단처럼 단정하지 않고 사용자가 조정 가능한 기본값으로 제공

### 4. 성장·섭취 추이

- 날짜별 체중 그래프와 급여량을 같은 기간에서 비교
- 급여 거부 또는 일부 섭취가 이어지는 구간 표시
- 먹이 종류·상태별 섭취 결과 집계
- CSV 내보내기와 동물병원 공유용 요약은 이후 단계에서 검토

## 검수 기준

- 전체 자동화 테스트 263개 통과
- 모바일 390×844, 데스크톱 1280×900 확인
- 1:3 메이팅 그룹의 암컷별 혈통 경고·메이팅 기록·클러치 페어링 연결 확인
- 냉동 마우스 호퍼를 `통먹이·해동·1마리·전부 먹음`으로 저장해 최근 기록과 달력 상세 표시 확인
- 일부 섭취량이 제공량 이상이면 저장을 막고 한국어 오류를 표시
- 알 상태 합계가 전체 알 수를 넘으면 저장을 막고, 등록 자손 수가 부화 수를 넘지 않음을 서버에서 확인
