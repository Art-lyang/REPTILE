# 프로젝트 현재 상태와 다음 작업

- 기준일: 2026-08-04
- 라이브: <https://ryangstudio.com/>
- 배포 대상: Cloudflare Workers 정적 자산
- 데이터베이스: Supabase, 라이브는 `supabase_v51.sql`까지 적용 및 검증 완료

이 문서는 현재 라이브 상태와 다음 작업 순서를 빠르게 확인하기 위한 기준 문서입니다.
세부 설계의 배경은 `STUDIO.md`, `AUTH.md`, `plans/linebreeding-goal-roadmap.md`를 함께 봅니다.

## 현재 공개 범위

- 모프 계산기: 레오파드게코, 크레스티드게코, 팻테일게코, 볼파이톤
- 크리처 케어로그와 브리딩 관리: 폐쇄 테스트 계정으로 운영
- 로그인: 기존 계정과 발급된 테스트 계정만 허용
- 일반 회원가입·비밀번호 재설정: 화면과 서버에서 일시 중단
- 이용약관·개인정보처리방침 링크와 광고 영역: 일시 숨김
- 공개 개체 갤러리 진입점: 일시 숨김

숨김은 화면만의 조치가 아닙니다. 신규 Auth 사용자 생성은 DB 트리거로도 막고,
계정 데이터 API는 인증 사용자로 제한합니다. 공개 개체 조회 RPC만 익명 접근을 유지합니다.

## 폐쇄 테스트 계정 운영

- 일반 회원 비교용 계정 1개와 프리미엄 회원 비교용 계정 1개를 관리자 경로로 발급했습니다.
- 로그인 화면과 계산기 계정 진입점에는 현재 폐쇄 테스트 중이라는 안내를 4개 언어로 표시합니다.
- 신규 계정은 정확한 이메일·짧은 만료시간·1회 소비 방식의 관리자 허용값이 있어야만 생성됩니다.
- 테스트 계정 발급 후 허용값은 모두 소비되어 현재 신규 가입 차단이 다시 닫혀 있습니다.
- 관련 DB 기준은 `supabase_v51.sql`, 화면 회귀 검사는 `tests/closed-beta-login.test.js`입니다.

- 암컷별 최대 3세대 공통 조상·직계 조상·혈통 누락 표시와 날짜별 메이팅 관찰 기록

- 유정·무정·발달 중지·부화·미확인 알 수와 실제 부화일·마감 상태 기록

## 유지 원칙

- 공개 모프 계산기에는 계산에 필요한 기능만 둡니다.
- 장기 프로젝트·크로스·선발·실제 결과는 브리딩 관리가 소유합니다.
- 멘델 확률과 라인브리딩 관찰 평가는 섞지 않습니다.
- 새 사용자 문구는 한국어·영어·중국어·일본어를 함께 추가합니다.
- 케어로그 I18n은 `care-i18n-ko/en/zh/ja.js`의 동일 키 계약과
  `care-i18n.js`의 공통 날짜·숫자·URL 경계를 사용합니다.
- 계정 I18n은 `login-i18n-ko/en/zh/ja.js`의 동일 키 계약과
