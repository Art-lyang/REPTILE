## 1. 레오파드 게코 모프 계산기 개선 방향

### 결론

현재는 모프 목록을 더 늘리는 것보다 **계산 결과를 실제 브리딩 계획과 기록으로 이어주는 기능**을 우선하는 편이 효과가 크다.

권장 우선순위는 다음과 같다.

1. 계산 결과를 브리딩 관리에 저장
2. 결과별 유전 근거 보기
3. 클러치 기준 예상 분포
4. 페어링 비교
5. 최근 계산 및 즐겨찾기
6. 모프 정보 카드와 자료 갱신일 표시

크로스 개체는 계산기 안에서 독립적인 부모 형질로 계속 확장하기보다, 크리처 케어로그 또는 브리딩 관리에서 계통·세대·선발 목표를 기록하는 방향이 적합하다.

---

### P0. 계산 결과를 브리딩 관리에 저장

계산 결과 하단에 **브리딩 관리에 저장** 버튼을 추가한다.

저장할 정보:

- 부모 A와 부모 B
- 각 부모의 비주얼 및 헷 형질
- 예상 새끼 모프와 확률
- 라인브리딩 및 크로스 표기
- 위험 조합 경고
- 목표 모프
- 사용자 메모
- 계산일

현재 브리딩 관리에서 계산기로 부모 조합을 보내는 흐름은 존재한다. 반대로 계산기에서 얻은 결과를 브리딩 프로젝트로 가져오는 흐름을 연결하면 서비스가 다음과 같이 완성된다.

> 내 개체 선택 → 모프 계산 → 결과 확인 → 페어링 저장 → 클러치 및 부화 결과 기록

#### 권장 버튼

- 주 버튼: `브리딩 관리에 저장`
- 보조 버튼: `다른 페어링과 비교`
- 저장 완료 안내: `브리딩 프로젝트에 저장했어요`

### P0. 결과별 유전 근거 보기

결과 표의 각 행을 누르면 해당 결과가 나온 이유를 유전자 단위로 펼쳐 보여준다.

예시:

```text
이클립스
비주얼 × het
→ 50% 비주얼
→ 50% het 보인자

블랙나이트 × 탠저린
→ 두 형질 모두 라인브리딩 형질
→ 멘델 유전 확률을 계산할 수 없음
→ 새끼의 실제 색감과 발현 정도는 개체마다 다를 수 있음
```

필요한 표시 항목:

- 부모의 유전형
- 각 부모가 전달할 수 있는 대립유전자
- 비주얼과 헷 확률
- 콤보 이름이 붙은 이유
- 라인브리딩 형질과 단일 유전자 형질의 구분
- 건강 또는 치사 위험 근거

특히 현재처럼 결과에 `100% 멜라텐져린`이 표시되는 경우, 이것이 외형 발현 100%를 의미하는 것으로 오해되지 않도록 별도 설명이 필요하다.

권장 문구:

> 라인브리딩 계열 표기입니다. 모든 새끼가 동일한 색감과 발현 정도를 보인다는 의미는 아닙니다.

### P1. 클러치 기준 예상 분포

상태: MVP 구현 완료 (2026-07-31) — 2·4·6개 프리셋, 직접 입력, 결과별 기대 마릿수와 최소 한 마리 출현 확률, 한국어·영어·중국어·일본어 지원.

사용자가 예상 알 수를 입력하면 확률을 기대 개체 수로 변환해 보여준다.

입력 예시:

- 2개
- 4개
- 6개
- 직접 입력

출력 예시:

```text
6개 알을 기준으로 한 통계적 기대값

25% 모프: 평균 1.5마리
50% 모프: 평균 3마리

실제 부화 결과를 보장하지 않습니다.
```

가능하면 다음도 함께 제공한다.

- 목표 모프가 최소 한 마리 나올 가능성
- 비주얼 개체 기대 수
- 특정 헷을 보유한 개체 기대 수
- 비생존 조합을 제외한 기대 수

MorphMarket의 현재 계산기도 클러치 또는 리터 크기를 기준으로 한 예상 통계를 제공한다.

- 참고: <https://support.morphmarket.com/article/44-take-the-tour>

### P1. 페어링 비교

상태: MVP 구현 완료 (2026-07-31) — 현재 페이지에서 최대 3개 페어링 저장, 목표 모프별 비주얼·보인자 확률, 건강 경고, 라인 방향과 도달 단계 비교. 공용 모듈로 구성해 다른 종 계산기에도 재사용 가능.

부모 한쪽을 바꾼 두 개 이상의 계산 결과를 나란히 비교한다.

비교 항목:

- 목표 모프 확률
- 비주얼 및 헷 비율
- 비생존 가능성
- 건강 주의 형질
- 라인브리딩 방향
- 목표까지 예상 세대

예시:

```text
페어링 A: 블랙나이트 × 탠저린
페어링 B: 블랙나이트 × 만다린
```

사용자는 어떤 페어링이 목표에 더 적합한지 빠르게 판단할 수 있다.

### P1. 최근 계산 및 즐겨찾기

상태: MVP 구현 완료 (2026-07-31) — 브라우저별 최근 계산 5개, 즐겨찾기, 부모 A/B 교환, 이전 계산 다시 불러오기, 한국어·영어·중국어·일본어 분리 저장을 지원한다. 부모 순서만 바뀐 동일 조합은 중복으로 쌓지 않으며, 저장값은 공용 교배 스냅샷 검증을 통과한 데이터만 사용한다. `내 개체를 부모 프리셋으로 불러오기`는 브리딩 관리 계정 기능 공개 시 연결한다.

추천 기능:

- 최근 계산 5개
- 즐겨찾는 조합
- 부모 A와 B 교환
- 이전 계산 다시 불러오기
- 내 개체를 부모 프리셋으로 불러오기

전체 모프 칩이 많아질수록 검색과 프리셋의 사용 가치가 커진다.

부모 선택 칩 또는 결과명을 누르면 간단한 모프 정보를 표시한다.

표시 항목:

- 한국어명과 영문명
- 별칭
- 유전 방식
- 슈퍼폼 여부
- 알려진 콤보
- 라인브리딩 또는 단일 유전자 구분
- 건강 주의 사항
- 자료 출처
- 마지막 자료 갱신일

사진을 추가할 경우에는 실제 결과를 보장하는 이미지로 보이지 않도록 다음 문구가 필요하다.

> 참고용 발현 예시입니다. 같은 모프도 계통, 성장 단계 및 개체에 따라 외형이 달라질 수 있습니다.

레몬 프로스트 관련 건강 경고는 연구 자료를 연결해 신뢰도를 높일 수 있다.

## 2. 현재 화면에서 함께 개선하면 좋은 부분

### 부모 선택

- 모프 검색은 잘 작동한다.
- 전체 콤보 칩이 처음부터 많이 노출되어 탐색 부담이 크다.
- 기본 상태에서는 목록을 접고 검색, 최근 선택, 즐겨찾기를 먼저 보여주는 편이 좋다.

### 계산 결과

- 큰 도넛 차트 때문에 실제 결과 이름이 첫 화면 아래로 밀린다.
- 결과 이름과 핵심 확률을 먼저 보여주고, 차트는 보조 정보로 배치하는 것을 권장한다.
- 일반적인 게코 그림은 특정 모프의 실제 외형으로 오해될 수 있으므로 `결과 이미지가 아닌 안내용 일러스트`임을 표시하거나 비중을 줄인다.

### 라인브리딩 안내

- 현재 설명은 내용은 충분하지만 문단이 길다.
- 아래처럼 짧은 카드로 나누는 편이 읽기 쉽다.

```text
계산 가능한 유전 형질
단일 유전자 형질로 확률을 계산합니다.

라인브리딩 형질
정확한 발현 확률을 계산할 수 없습니다.

크로스 개체
브리딩 관리에서 계통과 선발 목표를 기록합니다.
```

### 모바일

- 부모 A와 B를 고른 뒤 계산 버튼까지 스크롤 거리가 길다.
- 화면 하단에 `선택된 형질 · 계산하기` 고정 바를 두는 것을 권장한다.
- 모바일에서 아이콘만 표시되는 도움말 및 정보 버튼에도 스크린 리더용 이름을 유지해야 한다.

## 5. 게시 시 권장 사항

- 첫 이미지에는 계산기 메인 화면보다 실제 계산 결과가 보이는 화면을 사용한다.
- 부모 선택과 결과가 한 이미지에 함께 보이면 이해가 빠르다.
- 제목에 서비스명인 `량 스튜디오`를 앞세우기보다 `크레 모프 계산기`를 먼저 쓴다.
- `완벽하게 정확하다` 또는 `모든 모프를 지원한다` 같은 표현은 사용하지 않는다.
- 글 마지막에 누락 모프와 계산 오류 제보를 요청해 커뮤니티 참여를 유도한다.
- 같은 글을 여러 갤러리에 올릴 경우 첫 문단과 제목을 조금씩 바꿔 반복 광고처럼 보이지 않게 한다.
